# Software Quality — Review / Audit Checklist (SWEBOK v4, KA 12)

Produce a findings report: per-topic coverage, a defect/gap list with severity, and concrete fixes. Anchor findings to the topic map.

## Program gates
- Quality attributes **measurable**; integrity level set and rigor matched?
- QA (process) **and** QC/V&V (product) both present, not conflated?
- Static + dynamic + (formal, if warranted) analysis in the mix?
- Reviews multi-perspective with tracked actions?
- Defects **characterized** and feeding preventive action?
- Cost of quality visible?

## Severity
- Critical: no V&V on high-integrity software; defects with no root-cause loop.
- Major: QA conflated with testing; unmeasurable quality goals.
- Minor: review hygiene.
